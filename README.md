# TripMemo · 人生记忆地图

把「自己待过的地方」按**停留时长**画在地图上的个人记忆记录网站。

不预设你是"爱旅行的人"——住的学校、长住的出租屋、路过的城市、想去还没去的地方，
都可以放进来。**别人记"去过哪"，这个项目记"待了多久"。**

> 这是一个纯前端项目：**不需要服务器，也不需要数据库**，数据存在你自己的浏览器里。

---

## 一、怎么在本地跑起来

### 前提

- 已安装 **Python 3**（用来起一个本地静态服务器；本项目不需要任何第三方依赖）

### 三步启动

```bash
# 1、进入项目目录（就是你现在看到的这个文件夹）
cd 你的项目目录

# 2、启动本地静态服务器（这一条命令会一直占住终端窗口，别关）
python -m http.server 8000

# 3、在浏览器打开
#    http://localhost:8000
```

> **Windows 小技巧**：在文件资源管理器的地址栏里输入 `cmd` 按回车，可以直接在该目录打开终端，
> 省得手动 `cd`。

**成功现象**：终端输出 `Serving HTTP on ... port 8000`，浏览器里出现中国地图和左上角的搜索框。

**停止服务器**：回到终端按 `Ctrl + C`。

> **为什么不能直接双击 `index.html`？**
> 直接打开用的是 `file://` 协议，和 `http://localhost` 是两套环境。
> 用本地服务器更接近真实环境，也能避免一系列奇怪的问题。

**端口 8000 被占用的话**：换成 `python -m http.server 8001`，浏览器地址相应改成 `http://localhost:8001`。

## 二、首次使用：配置高德地图 Key

地图由**高德地图 JS API** 提供，需要一个 Key。

### 1. 申请 Key

1. 打开 <https://lbs.amap.com>，注册账号并完成**实名认证**
2. 控制台 → **应用管理 → 我的应用 → 创建新应用**
3. 在该应用下点 **「添加 Key」**：
   - **服务平台：必须选「Web端（JS API）」**（选错会导致地图加载失败）
   - 域名白名单：**留空**
4. 复制两样东西：**Key** 和 **安全密钥（securityJsCode）**
   > JS API 2.0 **两个都要**，只填 Key 地图不会显示。

### 2. 填进配置文件

把 `config.example.js` 复制一份，命名为 **`config.js`**，然后填入两串值：

```js
window.TRIPMEMO_CONFIG = {
  amapKey: '你的 Key',
  amapSecurityCode: '你的安全密钥'
};
```

> `config.js` **已被 `.gitignore` 挡住，不会被提交到 GitHub**。
> 另外提醒：前端代码里的 Key 在浏览器里是能看到的（按 F12），
> 所以真正的防线不是"藏起来"，而是**域名白名单**和**用量监控**。
> 个人开发者免费额度是 1 万次/月，本项目远用不到。

## 三、怎么用

| 功能 | 怎么做 |
|---|---|
| **添加地点（点击）** | 点地图上任意位置 → 在弹窗里填写 |
| **添加地点（搜索）** | 在搜索框输入地名（如「华中科技大学」）→ 从下拉里选一个 → 自动定位并填好名称与城市 |
| **查看某个地点** | 点地图上的点、时间轴卡片，或地点列表里的条目 |
| **修改 / 删除** | 在查看态点「编辑」 |
| **按类型筛选** | 地图左上角的「全部 / 长期居住 / 短期停留 / 旅游 / 想去」 |
| **设定主城市** | 输入城市名 → 点「设定」。地图上会出现锚点，并从它向其他城市连线（**线越粗 = 在那座城市待得越久**） |
| **备份数据** | 点右上角「导出 JSON」 |

### 关于「想去」

「想去」是**还没去过**的地方，所以它有三条特殊规则：
显示为最小的点、悬停显示「下一站」、**不进入时间轴、也不参与连线**。

## 四、你的数据存在哪（很重要）

数据保存在**浏览器的 `localStorage`** 里，**不上传到任何服务器**。

⚠️ **这意味着**：换电脑、换浏览器、清浏览器缓存、用无痕模式，**数据都可能丢失，而且无法恢复**。

**所以请定期点「导出 JSON」备份。** 那是目前唯一的保险绳。

## 五、项目结构

```
├─ index.html            唯一页面（4 个视图都在里面，靠切换显示）
├─ css/
│  └─ style.css          全站样式
├─ js/
│  ├─ main.js            入口：初始化、视图切换、导航
│  ├─ store.js           数据层：localStorage 读写、导出 JSON（唯一数据出口）
│  ├─ model.js           数据模型：停留时长、点大小 / 线宽算法
│  ├─ map.js             地图视图：打点、点大小、筛选、搜索、锚点、连线
│  ├─ detail.js          地点详情弹窗（查看态 / 编辑态 / 新增态）
│  ├─ timeline.js        时间轴视图
│  └─ places.js          地点列表视图（按城市分组）
├─ config.js             本地配置：高德 Key（**不提交**）
├─ config.example.js     配置模板（提交）
├─ research.md           需求研究
├─ PRD.md                产品需求文档（含 33 条验收标准）
├─ TECH_DESIGN.md        技术设计（技术路线、项目结构、数据流图）
└─ DESIGN.md             设计规则（颜色 / 字号 / 间距 / 交互状态 / 审查清单）
```

## 六、技术栈

- **原生 HTML / CSS / JavaScript**（不用框架、不用构建工具）
- **高德地图 JS API**（地图显示、搜索选点）
- **浏览器 localStorage**（数据存储）
- 不需要后端、不需要数据库
